  <name>Task 1: Add GLB render-cost stats + triangle-explosion retry loop in worker</name>
  <files>frontend/src/app/features/tools/step-converter/workers/stepConverter.worker.ts</files>
  <action>
Implement post-write geometry accounting and bounded retry-on-explosion.

1. Add a helper that summarizes GLB render-cost from GLB JSON (no BIN decode):

- Count total triangles robustly for both indexed and unindexed TRIANGLES primitives:
  - Treat missing `prim.mode` as `TRIANGLES` (mode `4`) per glTF default.
  - If `prim.mode` is not `TRIANGLES` (4), do not contribute to `triangles` (still count the primitive in `primitiveCount`).
  - If `prim.indices` exists: add `accessors[prim.indices].count / 3`.
  - Else (unindexed TRIANGLES): add `accessors[prim.attributes.POSITION].count / 3`.
- Count meshes, nodes, nodes-with-mesh, primitives, primitives-with-position.
- Include these stats in an object like `{ triangles, meshCount, nodeCount, primitiveCount, nodesWithMeshCount }`.

2. Define a triangle-explosion policy (pinned thresholds):

- Pin deterministic explosion thresholds (use these exact defaults):
  - `MAX_TRIANGLES = 5_000_000`
  - `MAX_PRIMITIVES = 50_000`
  - `isTriangleExplosion(stats)` returns true when `stats.triangles > MAX_TRIANGLES || stats.primitiveCount > MAX_PRIMITIVES`.
- Keep the thresholds in a single constant object so they can be logged/persisted into warnings.

3. Wrap GLB generation with a bounded retry loop:

- Max attempts: 3 total (attempt indexes 0, 1, 2).
- Always use absolute deflection during conversion attempts:
  - If `message.triangulate.relative === true`, force it to `false` for attempt 0 as well.
  - Record a warning when forcing this (`code: 'mesh/relative-forced-false'`) with the original + forced triangulation options.
- Pin a deterministic retry schedule (use this exact schedule):
  - Establish an `attempt0` baseline triangulation:
    - `linearDeflection0 = message.triangulate.linearDeflection ?? 1`
    - `angularDeflection0 = message.triangulate.angularDeflection ?? 0.5`
    - `relative0 = false` (forced)
  - Apply these attempt overrides:
    - Attempt 0: `{ linearDeflection: linearDeflection0, angularDeflection: angularDeflection0, relative: false }`
    - Attempt 1: `{ linearDeflection: linearDeflection0 * 2, angularDeflection: Math.min(1.0, angularDeflection0 * 1.4), relative: false }`
    - Attempt 2: `{ linearDeflection: linearDeflection0 * 4, angularDeflection: Math.min(1.2, angularDeflection0 * 1.8), relative: false }`
- After each attempt, compute `meshStats` from the GLB JSON and run `isTriangleExplosion(meshStats)`.
- If explosion detected, record a warning and retry unless this was the final attempt.
- Keep retries deterministic (no random, no time-based backoff).

4. Persist results into outputs:

- Add `meshStats` and `conversionWarnings` fields into the `metadata` object written to `${base}.metadata.json` and injected into GLB under `asset.extras.bunlarStepConverter`.
- Warning structure (use this exact shape):
  - `{ code: string; message: string; detail?: Record<string, unknown> }`
- For each explosion-triggered retry, append a warning:
  - `code: 'mesh/triangle-explosion-retry'`
  - `message` mentions attempt index and that meshing was coarsened
  - `detail` includes:
    - `attempt`, `thresholds`, `meshStats`, `triangulateUsed`
- If the final attempt still exceeds thresholds, append a final warning:
  - `code: 'mesh/triangle-explosion-unresolved'`
  - `detail` includes `attempt: 2`, `thresholds`, `meshStats`, `triangulateUsed`

5. Writer performance setting parity:

- In the worker’s manual `RWGltf_CafWriter` path (`convertStepDocToGlb()`), set `writer.SetMergeFaces(true)` if available.

Constraints:

- Warnings must be accumulated and surfaced only after conversion completes (no mid-stage ERROR).
- Do not introduce runtime decimation/simplification of GLB buffers; only coarsen OCCT tessellation inputs.
