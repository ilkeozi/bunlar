  <action>
Add triangle-explosion detection + mitigation to the Assembly Hierarchy Explorer conversion worker (parity with the Step Converter worker), and surface warnings minimally.

1. Add post-write mesh stats (no BIN decode):

- After each `converter.writeBuffer(..., 'glb', ...)` attempt, parse the GLB JSON chunk and compute:
  - `triangles` (robust for indexed + unindexed TRIANGLES primitives):
    - Treat missing `prim.mode` as `TRIANGLES` (mode `4`) per glTF default.
    - If `prim.mode` is not `TRIANGLES` (4), do not contribute to `triangles` (still count the primitive in `primitiveCount`).
    - If `prim.indices` exists: add `accessors[prim.indices].count / 3`.
    - Else (unindexed TRIANGLES): add `accessors[prim.attributes.POSITION].count / 3`.
  - `primitiveCount`, `meshCount`, `nodeCount`, `nodesWithMeshCount`

2. Pin explosion thresholds and a deterministic retry schedule (use these exact defaults):

- Thresholds:
  - `MAX_TRIANGLES = 5_000_000`
  - `MAX_PRIMITIVES = 50_000`
  - `isTriangleExplosion(stats)` when `stats.triangles > MAX_TRIANGLES || stats.primitiveCount > MAX_PRIMITIVES`
- Attempts: 3 total (0, 1, 2). Always keep `relative: false`.
- Retry schedule based on the attempted triangulation baseline:
  - Attempt 0: use provided triangulation (but force `relative: false`)
  - Attempt 1: `linearDeflection *= 2`, `angularDeflection = Math.min(1.0, angularDeflection * 1.4)`
  - Attempt 2: `linearDeflection *= 4`, `angularDeflection = Math.min(1.2, angularDeflection * 1.8)`

3. Implement bounded retry:

- If attempt 0 is an explosion, retry attempt 1; if attempt 1 is an explosion, retry attempt 2.
- If attempt 2 is still an explosion, still return the GLB (do not crash), but record an unresolved warning.

4. Capture structured warning detail and return it to the UI thread:

- Add `meshStats` and `conversionWarnings` to the worker DONE payload.
- `conversionWarnings` entries use shape `{ code: string; message: string; detail?: Record<string, unknown> }`.
- For each retry, append `code: 'mesh/triangle-explosion-retry'` with `detail: { attempt, thresholds, meshStats, triangulateUsed }`.
- When forcing `relative` to false, append `code: 'mesh/relative-forced-false'` with original/forced triangulation detail.
- If final attempt is still an explosion, append `code: 'mesh/triangle-explosion-unresolved'` with final stats.

5. Minimal warning surface:

- In `useAssemblyFile.ts`, when conversion completes and `conversionWarnings.length > 0`, emit a single `console.warn(...)` summary in dev builds only (`import.meta.env.DEV`).
- Do not add blocking UI, to keep the Explorer flow lightweight.
  </action>
