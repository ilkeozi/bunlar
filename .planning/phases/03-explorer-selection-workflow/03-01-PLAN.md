  <name>Task 1: Add feature-local Zustand store for selection + visibility + fit requests</name>
  <files>frontend/src/app/features/climate-tech/assembly-viewer/state/useAssemblyExplorerStore.ts</files>
  <action>
Create `useAssemblyExplorerStore` as the single source of truth for the Assembly Explorer workflow.

Store requirements (match Phase 03 locked semantics):

- Single-select only.
- Selection is allowed only for leaf/part nodes when selection originates from the tree.
- 3D selection uses an OCAF entry extracted from the picked mesh name.
- Click empty in 3D clears selection.
- Selection coming from 3D must auto-reveal in the tree (expand ancestors; scrolling handled by UI plan).
- Hidden-selected stays selected; selecting a hidden node in tree does NOT unhide it.
- Hidden objects are not pickable in 3D (enforced later by mesh visibility).

State shape (minimum):

- `nodeMap: AssemblyNodeMap | null`
- `selectedNodeId: string | null`
- `selectedOcafEntry: string | null` (OCAF `labelEntry`)
- `selectionSource: 'tree' | '3d' | 'program'`
- `expandedNodeIds: Set<string>`
- `explicitHiddenNodeIds: Set<string>`
- `isolateActive: boolean`
- `isolateSnapshot: Set<string> | null` (snapshot of explicitHiddenNodeIds when isolate is toggled on)
- `fitRequestId: number` and `fitRequestMode: 'selection' | 'visible' | null`
- `meshesByOcafEntry: Map<string, THREE.Mesh[]> | null` (mesh index set by the R3F model; consumed by outline/fit/visibility)

Actions (minimum):

- `setNodeMap(nodeMap)`
  - build/refresh an internal mapping `nodeIdByOcafEntry` for part nodes.
  - if `selectedOcafEntry` is set and `selectedNodeId` is null, resolve it.
- `selectNodeId(nodeId | null, source)`
  - when selecting non-null, set both `selectedNodeId` and `selectedOcafEntry` from the NodeMap node's `labelEntry`.
  - when selecting null, clear both.
- `selectOcafEntry(ocafEntry | null, source)`
  - set `selectedOcafEntry` and resolve `selectedNodeId` via `nodeIdByOcafEntry` when possible.
  - when source is `'3d'` and a node id is resolved, expand ancestors into `expandedNodeIds`.
- `toggleExpanded(nodeId)` (tree UX)
- `toggleHidden(nodeId)` (hide/show toggles apply to any node; subtree effects are derived later)
- `hideSelected()` and `showSelected()` (operate on `selectedNodeId` only; no-op if none)
- `toggleIsolate()`
  - on: snapshot current `explicitHiddenNodeIds`, then set `explicitHiddenNodeIds` to hide all leaf nodes except the selected node (if no selection, no-op)
  - off: restore snapshot verbatim
- `showAll()`
  - clear `explicitHiddenNodeIds`, clear isolate state, keep selection
- `requestFit(mode)`

  - increments `fitRequestId` and sets `fitRequestMode` (later consumed inside the R3F canvas)

- `setMeshesByOcafEntry(meshesByOcafEntry: Map<string, THREE.Mesh[]> | null)`
  - store the latest mesh index built from the currently loaded model
  - implementation note: keep this typed via `import type * as THREE from 'three'` to avoid runtime import

Implementation constraints:

- Use Sets/Maps immutably on updates (always create new `Set` instances when mutating) so React subscribers re-render.
- Keep all non-serializable indexes (e.g. Map lookups) internal to the store module unless a consumer truly needs them.
- Exception: `meshesByOcafEntry` is intentionally exposed because SelectionOutline/FitController need to read it.

  <action>
Add pure helpers to keep selection/visibility wiring deterministic and testable.

1. `utils/ocaf.ts`

- Implement `extractOcafEntry(name: string): string | null`.
- Use the repo-established pattern: match all occurrences of `\b\d+(?::\d+)+\b` and return the LAST match.

2. `utils/nodeMapIndex.ts`

Implement helpers over `AssemblyNodeMap` (from `frontend/src/app/features/climate-tech/assembly-viewer/types.ts`):

- `isLeafPartNode(node): boolean` (true for `kind === 'part'` AND `children.length === 0`).
- `getAncestorNodeIds(nodeMap, nodeId): string[]` (closest parent first or root-first; be consistent and document in naming).
- `getDescendantNodeIds(nodeMap, nodeId): string[]` (BFS/DFS ok; must include nested subtree).
- `getLeafPartNodeIdsInSubtree(nodeMap, nodeId): string[]`.
- `buildNodeIdByOcafEntry(nodeMap): Map<string, string>`

  - map `labelEntry -> nodeId` for leaf/part nodes.
  - if duplicates exist, keep the first encountered and ignore the rest (but do not throw).

- `getEffectiveHiddenLeafPartNodeIds(nodeMap, explicitHiddenNodeIds: Set<string>): Set<string>`

  - This is the canonical "effective hidden" derivation location (NOT the store): consumers compute it on-demand.
  - Expands each explicitly hidden node into all leaf-part descendants using `getLeafPartNodeIdsInSubtree`.
  - Returns a Set of leaf-part `nodeId`s.

- `getEffectiveHiddenLeafPartOcafEntries(nodeMap, explicitHiddenNodeIds: Set<string>): Set<string>`
  - Maps `getEffectiveHiddenLeafPartNodeIds(...)` to `labelEntry` strings.
  - Intended consumer: `visualizer/AssemblyModel.tsx` for applying `mesh.visible` via `meshesByOcafEntry`.

These functions are later used to:

- Auto-expand ancestors when selection comes from 3D.
- Compute isolate hide sets (all leaf parts except selected).
- Apply effective visibility in the 3D scene.
