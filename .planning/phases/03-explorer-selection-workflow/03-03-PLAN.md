  <action>
Implement the UI layer inside the existing Assembly Viewer page without introducing new panels beyond the tree.

1. `AssemblyExplorerPanel.tsx`

- Create a new panel component that renders:
  - `AssemblyExplorerToolbar` (actions apply to current selection)
  - `AssemblyExplorerTree` (hierarchy with expand/collapse, selection, per-node visibility toggle)
- The panel should fit in the existing left-side `<aside>` in `AssemblyViewerPage.tsx`.

2. `AssemblyExplorerTree.tsx`

- Render the NodeMap as a tree using `nodeMap.roots` and `nodeMap.nodes[nodeId].children`.
- Expand/collapse state is driven by `expandedNodeIds` in the store.
- Selection behavior:
  - Only leaf/part nodes are selectable.
  - Clicking a selectable row calls `selectNodeId(nodeId, 'tree')`.
  - Clicking a non-leaf row toggles expansion (no selection).
- Visibility behavior:
  - Every row has an eye toggle button.
  - Toggling visibility on a non-leaf node affects its subtree via derived effective hidden state (store already models this intent; 3D applies it).
  - Dim the label when the node is effectively hidden.
- Auto-reveal:
  - When selection comes from 3D (`selectionSource === '3d'`) and `selectedNodeId` changes, scroll the selected row into view and ensure its ancestors are expanded (expansion should already be handled by the store; tree handles scroll).
- Clicking the eye button must not change selection (stop propagation).

3. `AssemblyExplorerToolbar.tsx`

- Add buttons:
  - Hide (hide selected)
  - Show (show selected)
  - Isolate (toggle; restores previous visibility when toggled off)
  - Show all (unhide everything + clear isolation + keep selection)
  - Fit (requests fit to selection if selection exists; otherwise requests fit to visible)
- Disable actions when their preconditions are not met (e.g. no nodeMap loaded).

4. Wire into `AssemblyViewerPage.tsx`

- When `useAssemblyFile(...)` yields `metadata?.nodeMap`, call store `setNodeMap(metadata.nodeMap)`.
- Render `AssemblyExplorerPanel` in the aside (near the existing viewer controls).
- Keep existing auto-rotate + reset view controls unchanged.
